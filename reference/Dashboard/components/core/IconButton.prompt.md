One-sentence: icon-only button (28/34/40px) for toolbars and card affordances.

```jsx
<IconButton label="Bookmark gig"><Icon name="bookmark" /></IconButton>
<IconButton label="Filters" variant="outline"><Icon name="sliders-horizontal" /></IconButton>
```

Notes: default is `ghost` (transparent, hovers to parchment). Icons are Lucide at stroke-width 1.5.
