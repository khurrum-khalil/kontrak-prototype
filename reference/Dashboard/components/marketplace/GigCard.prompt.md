One-sentence: the marketplace's core list item — one posted brief with client, rate and practice-area tags.

```jsx
<GigCard title="Review a SaaS reseller agreement" client="Northlane Studio" location="Remote · UK"
  rate="£420" period="fixed" tags={['Commercial','Contract review']} badge="Visa-safe" rating={4.9} reviews={22} />
```

Notes: rate is always the loudest element after the title. Keep tags to three max in list views.
